# راهنمای نویسندهٔ wowheadFA — فرمت v2 (بلاک‌ها و آیتم‌ها)

این سند برای نویسنده‌های انسانی و ایجنت‌های هوش مصنوعی است. قواعد سبک و
اصول بازنویسی در [`config/prompt.md`](../config/prompt.md) آمده؛ اینجا فقط
**جعبه‌ابزار چیدمان** و چرخهٔ آیتم‌ها توضیح داده می‌شود.

## چه چیزعی عوض شد؟

تا دیروز `body_fa` فقط آرایه‌ای از رشته‌های پاراگراف بود — خبر «متن خالی»
منتشر می‌شد: آیتمی که در متن ذکر می‌شد نه لینک می‌شد نه تولتیپ داشت و هیچ
راهی برای تیتربندی، فهرست، نقل‌قول، جدول یا کارت آیتم نبود. از v2:

- `body_fa` آرایه‌ای از **رشته (پاراگراف)** و **بلاک شیء‌ای** است.
- هر متن می‌تواند **مارکر آیتم** `[[item:...]]` داشته باشد.
- سایت هر نام آیتمِ شناخته‌شده را حتی بدون مارکر خودکار لینک می‌کند.
- آیتم‌های تازه‌ای که خبر معرفی می‌کند **خودکار به دیتابیس wowfarsi اضافه
  می‌شوند** (بخش پایین).

## واژه‌نامهٔ بلاک‌ها

| بلاک | JSON | کی استفاده کنیم |
|---|---|---|
| پاراگراف | `"متن"` یا `{"t":"p","x":"متن"}` | روایت پیش‌فرض؛ ۱ تا ۴ جمله |
| تیتر بخش | `{"t":"h","x":"تیتر"}` | مقالهٔ بلندتر از ~۴ پاراگراف را بخش‌بندی کن؛ ۱ تا ۴ تا در هر خبر |
| فهرست | `{"t":"ul","xs":[...]}` | ۳ مورد موازی و بیشتر: جوایز، تغییرات، نکته‌ها |
| فهرست شماره‌دار | `{"t":"ol","xs":[...]}` | فقط مراحل ترتیبی |
| نقل‌قول | `{"t":"quote","x":"...","by":"Blizzard — Kaivax"}` | فقط نقل‌قول واقعیِ موجود در منبع |
| نکته | `{"t":"note","x":"...","kind":"tip\\|warn\\|info"}` | بینش کاربردی (tip)، دام (warn)، بافت (info) |
| جدول | `{"t":"table","head":[...],"rows":[[...]]}` | مقایسهٔ عددی به‌جای پاراگراف عددی |
| تصویر | `{"t":"img","src":"https://...","cap":"کپشن"}` | فقط URL همان تصویر داخل مقالهٔ منبع |
| کارت آیتم | `{"t":"item","id":277283}` | آیتم(های) اصلی خبر |
| مارکر | `[[item:Exact EN Name]]` در هر متن | هر اشارهٔ درون‌متنی به آیتم |

سه نمونهٔ کامل و واقعی: [`config/examples-v2.json`](../config/examples-v2.json).

## قواعد سخت آیتم‌ها

1. **نام آیتم هرگز فارسی نمی‌شود** — در متن و داخل مارکر همیشه املای
   انگلیسیِ دقیقِ منبع.
2. **ID را فقط از خود مقالهٔ منبع بردار** (لینک‌های `/item=277283` داخل
   متن Wowhead). ID از خودت نیساز.
3. اگر ID نداری ولی نام دقیق را داری: `[[item:Exact EN Name]]` — سایت خودش
   نام را به ID دیتابیس وصل می‌کند.
4. برچسب دلخواه فارسی مجاز است: `[[item:Aqir Research Satchel|سچل پژوهش]]`
   — ولی فقط وقتی برچسب واقعاً خواناتر باشد؛ پیش‌فرض همان نام انگلیسی است.

## چرخهٔ خودکار آیتم‌ها (سمت wowfarsi.ir)

```
خبر منتشرشده (news.json)
   │  آیتم‌ها: {"t":"item","id":N} / [[item:ID]] / [[item:Name]]
   ▼
tools/news_sync.py          هر ID که در دیتابیس wowfarsi نیست را از
  (هر ۳۰ دقیقه در CI)        Wowhead می‌گیرد و به data/retail/db/items-news.json
                             اضافه می‌کند ← صفحهٔ item/<id>-<slug>.html خودکار
                             ساخته می‌شود
   ▼
tools/build_news.py         بدنهٔ v2 را رندر می‌کند: کارت آیتم با آیکون و
                             استت، چیپ درون‌خطی رنگی با تولتیپ هاور،
                             news/tips.json برای تولتیپ صفحات پویا
   ▼
اگر فقط نام بود و ID نداشت ← data/retail/db/news-missing.json
   (نیاز به بازبینی انسانی: ID را پیدا کن و در ویرایش بعدی بگذار)
```

یعنی: اگر خبری آیتمی را معرفی کند که هنوز در دیتابیس wowfarsi نیست، تا
نیم‌ساعت بعد خودش به دیتابیس اضافه و صفحه‌اش ساخته شده و در خبر لینک‌دار با
تولتیپ نمایش داده می‌شود — کاری دستی لازم نیست.

## گیت‌های کیفیت (qa_check)

- `G9` شکل بلاک‌ها را اعتبارسنجی می‌کند (نوع ناشناخته، جدول بی‌سطر، img
  بدون https … ⇒ مردود).
- `G7` بدنه را ۲ تا ۱۴ بلاک می‌پذیرد؛ پاراگراف‌های ساده همچنان ≥۴۰ نویسه.
- `G6` مارکر `[[item:...]]` را syntax قانونی می‌داند؛ هر `[[` دیگری
  همچنان خطاست.
- متن بلاک‌ها (تیتر، فهرست، جدول…) داخل گیت‌های G1 تا G5 شمرده می‌شود —
  نام آیتمِ از خودتان‌ساخته در G5 می‌گیرد.
