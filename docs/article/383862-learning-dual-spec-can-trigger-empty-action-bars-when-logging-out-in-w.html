باگ خالی شدن Action Barها پس از یادگیری Dual Spec هنگام خروج از بازی

2026-11-12 22:45 UTC نگارش و بازبینی خودکار با gemini-flash-latestباگ Dual Spec رابط کاربری

یادگیری قابلیت Dual Spec ممکن است به‌طور تصادفی باعث پاک شدن توانایی‌ها از نوار اکشن پس از خروج از بازی شود.

قابلیت Dual Spec در لول 40 با قیمت 50 گلد قابل خریداری است و امکان داشتن درخت تلنت دوم را برای بازیکنان فراهم می‌کند. با این حال، پس از یادگیری این قابلیت، باگی آزاردهنده ممکن است هنگام خروج از بازی رخ دهد.

بر اساس گزارش‌ها، پس از یادگیری Dual Spec ممکن است پس از خروج از بازی، برخی از Action Barها به‌صورت تصادفی ریست شوند. این اتفاق همیشگی نیست و هربار می‌تواند نوارهای متفاوتی را تحت تأثیر قرار دهد. اگرچه این ایراد تأثیری روی توانایی‌های مبارزه نمی‌گذارد، اما ورود به بازی و مواجهه با نوارهای کاملاً خالی خسته‌کننده است.

💡 به دلیل وجود این باگ، بسیاری از بازیکنان به استفاده از ادآن Myslot روی آورده‌اند؛ ابزاری که برای ذخیره و ایمپورت تنظیمات UI طراحی شده و برای بازگرداندن سریع نوارهای خالی‌شده بسیار کاربردی است.
