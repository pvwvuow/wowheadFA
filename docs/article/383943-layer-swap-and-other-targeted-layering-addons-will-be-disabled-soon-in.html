از کار افتادن ادان‌های هدف‌گیری Layer در WoW: Forever با تغییرات API

2026-11-20 19:00 UTC نگارش و بازبینی خودکار با gemini-flash-latestهاتفیکس WoW Forever ادان تغییرات API

بلیزارد با ایجاد تغییراتی در API بازی، امکان هدف‌گیری دقیق و جابه‌جایی هدفمند میان لایه‌ها را در به‌روزرسانی آیندهٔ WoW: Forever غیرفعال می‌کند.

در هاتفیکس پیش‌روی بازی WoW: Forever، ادان‌های هدف‌گیری لایه‌ها دیگر کار نخواهند کرد؛ چرا که فراخوانی‌های مختلف API که شناسهٔ رلم (realm ID) را نمایش می‌دادند، به‌زودی مبهم‌سازی (obfuscated) خواهند شد.

یکی از ادان‌های محبوب فعلی در CurseForge برنامهٔ Layer Swap است که به تسهیل جابه‌جایی میان لایه‌ها (layer hopping) کمک می‌کند. بازیکنان به دلایل متعددی از این قابلیت استفاده می‌کنند؛ دلیل اصلی پیدا کردن فازی تازه در زمان وجود رقابت در فاز فعلی است و همچنین در مواقعی که برخی بازیکنان در لایه‌های خاصی با باگ مواجه می‌شوند کاربرد دارد. این ادان به کاربران امکان می‌دهد تعداد تقریبی لایه‌ها را ببینند، متوجه شوند آیا قبلاً در یک لایه حضور داشته‌اند یا خیر، و مستقیماً وارد لایهٔ مدنظرشان شوند.

عملکرد ادان‌های جابه‌جایی لایه

ادانی مانند Layer Swap دو کار اصلی انجام می‌دهد:

  • تسهیل دعوت به لایهٔ جدید از طریق خودکارسازی ارتباطات.
  • امکان ردیابی و هدف‌گیری لایه‌های مشخص.

بلیزارد از زمان اکسپنشن Midnight، تغییرات ادان‌ها را از طریق دیسکورد WoWUIDev به توسعه‌دهندگان اطلاع‌رسانی می‌کند و اکنون با انتقال Forever به معماری مدرن، ارائهٔ این به‌روزرسانی‌ها در آن سرور دیسکورد نیز آغاز شده است.

اطلاعیهٔ تغییرات API

در نسخهٔ آزمایشی Midnight 12.1.7 PTR و بخش Addon Security: شناسهٔ realm ID در GUIDهای مربوط به creature، vehicle، pet و game object همراه با server ID و spawn ID مبهم‌سازی می‌شود. این تغییر در هاتفیکس آیندهٔ 1.60.1 برای Forever نیز اعمال خواهد شد. در به‌روزرسانی Forever 1.60.1 Live Update 2 بخش متفرقه: رابط‌های مختلف API که نام یا شناسهٔ رلم را برمی‌گردانند، به جای این مقادیر یک رشتهٔ خالی یا مقدار صفر بازمی‌گردانند. این شامل مواردی مانند GetRealmName، GetRealmID و توابع C_BattleNet می‌شود که خروجی اکانت بازی آن‌ها حاوی اطلاعات رلم است. این تغییر فقط مربوط به WoW Forever است.

— Blizzard — WoWUIDev Discord
ℹ️ تغییرات مربوط به برگرداندن رشتهٔ خالی یا صفر در توابع نام و شناسهٔ رلم، منحصراً روی WoW Forever اعمال می‌شود.

تأثیر بر ادان‌ها و وضعیت آینده

این تغییرات با حذف روش‌های تشخیص شناسهٔ رلم، ادان‌های جابه‌جایی لایه را از کار می‌اندازند. بر اساس توضیحات سازندهٔ ادان Layer Swap، جابه‌جایی زمانی رخ می‌دهد که بازیکن وارد گروه کاربری در لایهٔ دیگر شود و ادان لایهٔ فعلی بازیکن را با خواندن GUID موجودات (creature GUIDs) تشخیص می‌دهد. با حذف این اطلاعات، امکان مقایسه و تمایز لایه‌ها از دست خواهد رفت.

این به‌روزرسانی مانع تعویض کلی لایه‌ها در آینده نمی‌شود، اما هدف‌گیری مستقیم لایه‌های خاص دیگر امکان‌پذیر نخواهد بود؛ مگر آن‌که راهکار دیگری پیدا شود. در نتیجه، بازیکنان باید به شکل تصادفی میان لایه‌ها جابه‌جا شوند تا لایهٔ مورد نظر خود را بیابند و هیچ تضمینی وجود ندارد که فرد دیگر حتماً در لایهٔ متفاوتی قرار داشته باشد.
