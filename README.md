# WoWhead FA — اخبار ورلد آو وارکرفت به فارسی

سایت: **https://pvwvuow.github.io/wowheadFA/**

اخبار Wowhead به‌صورت خودکار دریافت می‌شود، سپس **بازنویسی اورجینال فارسی**
(نه ترجمهٔ تحت‌اللفظی) با ذکر منبع منتشر می‌شود.

```
Wowhead RSS ──▶ data/articles/*.json (status=new)
                    │
                    ▼  مترجم/نویسنده با API خودش (BYOK)
        ① وب: https://pvwvuow.github.io/wow/news-translate.html
           (لینک بده + کلید API خودت → پیش‌نویس → Issue → انتشار خودکار)
        ② یا CLI: python tools/write_article.py --id <ID> --model <MODEL>
                    │
                    ▼  گیت‌های QA خودکار (tools/qa_check.py)
             pass ──▶ status=published ──▶ docs/ ──▶ Pages
```

## جریان وب (برای همهٔ مترجم‌ها)

1. صفحهٔ **اخبار** سایت اصلی: https://pvwvuow.github.io/wow/news.html —
   اخبار منتشرشده + صف ترجمه (خودکار از `news.json` همین ریپو).
2. صفحهٔ **مترجم**: https://pvwvuow.github.io/wow/news-translate.html —
   لینک Wowhead + کلید API خودت (فقط در مرورگرت استفاده می‌شود، جایی ارسال
   نمی‌شود) → مدل متن کامل را می‌خواند و مقالهٔ اورجینال فارسی می‌نویسد →
   ویرایش + پیش‌QA → ثبت با یک Issue.
3. Workflow `publish-article` در همین ریپو: متن اصلی را سمت سرور می‌گیرد،
   گیت‌های کامل `qa_check` را اجرا می‌کند و در صورت قبولی خودکار منتشر و
   Issue بسته می‌شود. اگر خبر قبلاً منتشر شده باشد، Issue با پیام
   «تکراری» بسته می‌شود.

API داده برای سایت اصلی: `https://pvwvuow.github.io/wowheadFA/news.json`
(`published` با متن کامل + `queue` عناوین انگلیسی در انتظار ترجمه).

## اجزای ریپو

| مسیر | نقش |
|---|---|
| `tools/fetch_news.py` | پولر RSS واوهد (هر ۲۰ دقیقه با Actions) + دریافت تکی با `--url` |
| `tools/write_article.py` | نویسندهٔ هوشمند BYOK — پرامپت ما + مدل دلخواه شما |
| `tools/publish_from_issue.py` | انتشار خودکار از Issue مترجم وب + اجرای گیت‌ها |
| `tools/qa_check.py` | گیت‌های سخت‌گیرانهٔ کیفیت (تایپوگرافی، اعداد، اسم‌ها، بازنویسی) |
| `tools/build_site.py` | ساخت سایت استاتیک فارسی RTL + SEO + `news.json` در `docs/` |
| `config/prompt.md` | قواعد سرِمقاله‌نویسی ما (system prompt) |
| `config/site.json` | برندینگ، دیس‌کلیمر، آدرس پایه |

## قواعد محتوا

- بازنویسی اورجینال، **نه ترجمهٔ ۱:۱** — حقایق و اعداد حفظ می‌شوند.
- منبع هر خبر با لینک به Wowhead درج می‌شود (خودکار).
- اسم اسپل/آیتم/پچ به انگلیسی می‌ماند (مطابق سیاست پروژهٔ WoWFA).
- سایت غیررسمی است و دیس‌کلیمر ترademarک دارد؛ takedown سریع پاس داده می‌شود.

## سیاست حق نشر (مهم)

- **متن انگلیسی منبع هرگز ذخیره نمی‌شود** — نه در گیت، نه در Issue، نه در لاگ.
  متن فقط لحظهٔ بازنویسی در حافظهٔ همان اجرا زندگی می‌کند و بعدش دور ریخته می‌شود.
- به‌جای متن، فقط `qa_facts` نگه می‌داریم: فهرست اعداد مهم + واژه‌های انگلیسی
  مقاله (fact‌های غیرقابل کپی‌رایت) برای این‌که گیت‌های کیفیت G4/G5 بدون متن
  منبع هم کار کنند.
- payload مترجم وب هم دیگر شامل متن انگلیسی نیست؛ سرور خودش متن را موقت
  می‌گیرد و فقط فکت‌ها را نگه می‌دارد.
